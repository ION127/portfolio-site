### Terraform으로 만든 AWS

- `envs/dev` 한 환경을 Terraform으로 관리합니다. VPC(2 AZ, public · private 서브넷), 공개 · 내부 ALB, ECS Fargate 서비스 7개, RDS PostgreSQL, ElastiCache(Valkey), Kafka · Mosquitto용 EC2, Cloud Map, Secrets Manager, Site-to-Site VPN까지 코드로 정의했습니다.
- 상태는 S3와 DynamoDB 락으로 보관합니다. PR에서는 `fmt · validate · plan`, main에서는 `apply → db-init → 엣지 배포(SSM)`까지 GitHub Actions가 이어서 실행합니다.
- 실수로 지우지 않도록 destroy는 `destroy-dev` 같은 확인 문자열을 입력해야만 돌아갑니다.

### 배포 파이프라인

서버는 변경된 경로만 감지해 빌드 · 테스트하고, CI를 통과한 서비스만 ECR에 올려 ECS에 배포합니다. 승객 모바일 웹은 CodeDeploy Blue/Green으로 배포하고, 실패하면 자동으로 되돌립니다.

### 비용을 줄인 방법

- `runtime_enabled=false` 한 번으로 NAT · ALB · ECS · RDS · EC2를 내리고, VPC · ECR · Secrets처럼 다시 만들기 번거로운 것만 남깁니다.
- 내리기 전에 RDS 스냅샷을 자동으로 만들고, 다음 apply 때 가장 최근 스냅샷으로 자동 복원합니다.
- Kafka EC2를 t3.medium에서 t3.small로 줄이고, bastion을 없애 SSM으로만 접속하고, 로그 보존을 7일로 줄이고, 차량별 로그를 DEBUG로 내려 CloudWatch 비용을 줄였습니다.
